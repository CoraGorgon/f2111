PAGINA DE CUMPLEAÑOS - INSTRUCCIONES

1. Descomprime el ZIP.
2. Abre la carpeta "cumpleanos_para_mi_novia".
3. Entra a la carpeta "fotos".
4. Reemplaza las imágenes de ejemplo por tus fotos, usando EXACTAMENTE estos nombres:
   - portada.jpg
   - recuerdo-1.jpg
   - recuerdo-2.jpg
   - recuerdo-3.jpg

   Puedes usar JPG o convertir tus fotos a JPG. Si tus fotos tienen otro formato,
   conviértelas o cambia la extensión tanto en el nombre del archivo como en index.html.

5. Abre index.html con doble clic para ver la página en tu navegador.

PERSONALIZAR EL MENSAJE
- Abre index.html con Bloc de notas o VS Code.
- Busca el texto de la carta y reemplázalo por tus propias palabras.
- Puedes cambiar "mi amor", "mi persona favorita" y los demás textos.

PUBLICARLA EN INTERNET
Puedes subir la carpeta completa a un servicio de hosting estático, por ejemplo
GitHub Pages, Netlify o Cloudflare Pages. Sube index.html, styles.css, script.js
y la carpeta fotos completa. No subas solamente el archivo HTML.

No necesita instalar nada ni usar servidor para verla localmente.
